# H3 短剧分镜生成规范（小说→AI竖屏短剧）

## 目的

把小说/故事可靠地转化为可直接驱动"字字动画 + MiniMax H3"生成视频的**分镜剧本**。本技能沉淀了《怒海狂龙》项目两轮实测评审出的全部模型脾性规则，跨剧集、跨小说复用——换一部剧不需要重新踩坑。

## 使用时机

- 用户要求"小说转短剧/分镜剧本/AI短剧"
- 用户提到 字字动画、MiniMax H3、竖屏短剧生成
- 用户要求审查/修订已有分镜剧本

## 硬约束（每集铁律）

> **真源声明（防多处漂移）**：本表与 `H3分镜生成通用规范.md`（仓库根目录；运行时副本 `Toonflow-app/data/skills/production_skills/h3_storyboard_general_spec.md`） 第一节「格式硬约束」同源，此处仅为**速查摘要**。**两处不一致时一律以规范为准**，并须回填修正本文件。镜型判据、标注格式、镜型参数表与集级护栏见规范第二节附《镜型标注与镜型参数表》。

| 项 | 标准 |
|:--|:--|
| 分镜时长 | 统一 **12 秒**（生成时逐镜手动设定时长） |
| 每集 | ≤8分镜 = 96秒（≤2分钟红线），尾钩收尾 |
| **镜型标注** | **每镜必须标注镜型**（写在标题行 `｜镜型：…〔依据：…〕`）：**对白镜／画外音镜／动作镜**。**判据（按顺序自问，第一个"是"即定）**：① 有「施力→接触／落空→受力反馈」链 → **动作镜**（即使带台词）；② 画面内有人开口 → **对白镜**；③ 有画外音／内心独白／旁白 → **画外音镜**；皆否＝**违规镜**（须并入相邻镜）。**最易错的一条：逼近／对峙／举刀威胁／指尖悬停不接触＝对白镜**（无接触、无受力⇒无攻防链）；凡**接触类**冲突（耳光、推搡、夺物、拖拽、撞击、载具灾难）＝动作镜。动作镜须带"（有声音承载）／（无声音承载）"，子类（载具/灾难、群戏）照格式写全；闪前／闪回另加正交标签。**流程：AI 初标 → 编剧复核确认**（AI 只按判据判、依据必填 ≤12 字、**不确定标"待确认"且禁止猜**、不得改写△描述迁就判据；编剧首集全量复核、其后每集抽 2–3 镜、重点核对三类临界镜）。**完整判据（含边界裁决表）、参数表与集级护栏见规范二·附——本条为极简速查，二者不一致时以规范为准** |
| 台词 | 每镜台词总字数 **≤46 字（含标点，台词+画外音/内心独白合计）**；单句台词**不设字数上限**；台词过密时相应压缩（**动作镜可为 0 字**） |
| 台词覆盖率 | **最大限度消灭「无声音承载」的镜**——定义为**既无对白、也无画外音／内心独白**；**只有动作镜允许无声音承载**。注意：**画面里没人开口 ≠ 无台词**，带画外音／旁白／内心独白的镜属达标形态（无人物的全空镜亦可由画外音承载）。做法：开场/收尾/过渡动作优先并入相邻有声音镜——作为其首/尾节拍，用台词或画外音承载（画外音镜推提示词时须声明对应人物嘴唇保持闭合）；无声音承载镜**每集 ≤1 个**（动作密集集 ≤3 且不得连续 2 镜无声音，见规范"集级护栏"段） |
| 每镜人物 | ≤4人；群体规模用音效/光效/跨镜具名龙套表达，禁画"人影" |
| 角色具名 | 画面描述禁"他/她/壮汉/2个人"；龙套须具名；**身体部位特写须归属具名角色**并锁服装连续性 |
| 实体名称锁定 | 角色/场景/道具必须使用本剧《资产名称锁定表》的唯一锁定名称，一字不差；新实体先登记再使用（守则27） |

**动作镜额外适用守则**：11 动作尺度放开（两条红线不变）｜17 打斗禁关节技与精细擒拿｜22 单镜打斗只允许一对攻防｜23 恐惧/逃跑行为逻辑；动作编排按规范**第七节《动作戏编排（设计层·真人实拍版）》**，其**英文写法与生成侧硬前提**（一镜只能承载一对攻防／受力结果必须可验证／速度感来自结构而非动作速度）由下游视频推理模板承载——见「H3 3D仿真人短剧推理」模板（`Toonflow-app/src/constants/h3VideoPromptTemplate.ts`，设置 → 提示词管理可查看）**规则 36「动作与特效」与规则 38「动作物理预检」**。**注意：凡接触类物理冲突（耳光、推搡、夺物、拖拽、撞击、载具灾难）一律标动作镜，与"这集是文戏还是打戏"无关。** 〔文〕〔武〕〔通〕完整索引见规范第二节"镜型适用索引"，本文件不重复。

## 二十七条生成守则（模型脾性，实测+专家审查沉淀）

> **真源与优先级**：本守则区与 `H3分镜生成通用规范.md`（仓库根目录；运行时副本 `Toonflow-app/data/skills/production_skills/h3_storyboard_general_spec.md`） 第二节同源（含守则27 实体名称锁定）。**两处不一致时以规范为准**并回填本文件；镜型适用性以规范"镜型适用索引"为准。

1. **说话者必须入画**——画外音会被错配给画面人物；前景肩背入画时写明"背对镜头全程不开口"。
2. **一镜一景别一动作链**——禁镜内连续运镜变形（下摇/上摇中变化景别）、禁双重运镜（横摇+推近）。注：官方支持单条生成内**多shot硬切**语法（`[Shot N] At 00:0X.500, the camera cuts to...`，切开后每shot仍单一景别+单一动作），硬切≠连续运镜变形；多shot硬切的实测稳定性待试点，默认仍一分镜一生成。
3. **锁轴线**——相邻镜头同人物同场景写死"机位站位与上一镜完全相同"，用过肩镜头锁定；可用上一镜末帧作下一镜首帧参考图。
4. **慢动作全面后期化**——生成一律正常速度；高潮瞬间后期对0.5-1秒做曲线变速+光流补帧，剧本标`【后期慢放：第X-Y秒】`；禁整镜慢动作、禁镜内定点变速（模型原理性不可执行）。
5. **手部动作分级**——抓取/挥击/拖拽/推搡可直用；长镜头精细微动作（打字/穿针/晃动小物件）留后期或删。
6. **提示词禁自相矛盾**——"逼近"与"位置不变"互斥类错误是崩坏诱因；模板符号残留清零。
7. **全局风格尾缀**——剧集标题下声明一次（写实题材默认"写实真人实拍质感，冷色调，竖屏9:16"），不逐镜重复。
8. **字幕严禁进入生成输入**——模型文字渲染不可靠（中文变英文/乱码）；负面提示词必含"画面中出现文字、字幕、水印、英文字母"；字幕一律后期叠加。
9. **特写必须锚定比例**——"手伸向头/脸"是巨手畸形高发区：指定主体锚（"头部是画面最大元素"）+从属元素相对大小+悬停距离不接触。
10. **动作显式限定力度与情绪**——中性动词（走向/俯身/伸向）会被渲染成温柔平缓；反派/暴力/急迫动作必须写力度词（粗暴/猛地/一把攥住/狠狠）+表情（狞笑/凶光/惊恐）+否定式（"绝非轻抚"）。
11. **动作尺度**——打斗/拖拽/抓发/挥械/撞击/爆炸可直给，表现力优先；仅两红线：无血腥（喷溅/断肢/伤口特写）、无色情暴露；暴力结果可用出画/黑屏/音效承接。
12. **节拍密度与开场**——每镜承载1个动作链（2-3连续节拍，同场景自然延续，禁独立事件硬拼）；台词与动作并行，且按硬约束执行台词密度（**≤46字/镜**，优先并行台词）；**取消纯定场镜与纯动作过渡镜**——开场/收尾动作并入相邻有声音镜（画外音或对白承载），定场信息由后期字幕承载。
13. **画面描述禁入元语言**——△描述只写视觉/动作/声音；制作口径与审核说明（"无血迹""只有蛮力"）放镜外统一说明或负面提示词；出场人数与画面描述中的人数必须对账。
14. **衔接转场必须具体可见**——只写谁做了什么/怎么切；禁悬念式模糊指代（"一道黑影疾至"）；悬念靠剪辑顺序与音效制造，转场可写人物反应（"动作僵住，惊恐望向画外"）。
15. **群体规模用声音与光效**——"隐约人影/众人攒动"=模糊指代+畸变人影+超员三重雷区。安全表达：音效（脚步/喊杀声由远及近）、光效（手电光柱逼近）、跨镜累积具名龙套。
16. **隐私部位与体液细节禁入描述**——"裤裆湿了"类=畸变+审核误判+视觉不可辨识三重风险；狼狈/羞辱用动作（连滚带爬/双腿打颤）+声音（破音哀嚎）+台词呈现。
17. **打斗禁关节技与精细擒拿**——"折腕/反拧/锁技"会被慢速化拖沓化；打斗只用大开大合动作（劈/砍/扫/肘击/踹/拽/撞），速度靠力度词+速度词（电光火石/同一瞬）；挨打方也必须有攻击动作，禁"呆立挨打"。
18. **跨镜道具必须锁定外观，或同镜完成**——"上镜掷出→下镜命中"两次生成外观必不一致；优先同镜完成，跨镜则两镜写一致锁定描述并录道具档案。
19. **一镜一空间尺度，载具必须建档**——禁一镜内混合近景人物动作与远景大场面运动（会自造"另一艘船/车"）；人物镜与载具/大场面镜分开；载具外观写入场景档案并配参考图。
20. **多图参考推提示词走官方 Ref2VA 六段结构（2026-09-12 对齐官方）——适用环节：下游推提示词**。模板：`subject_definitions`（角色/场景定义，引用标签 `<Picture N>` 全段一致）→ `summary` → `retention_analysis`（必须保留的参考元素）→ `detailed_description`（时间线：首帧锚→动作启动→连续发展→结果反应，每个细节可见或可闻）→ `overall_soundscape`（环境声，不含对白）→ `non_diegetic_music`（配乐，禁抽象情绪词）。官方原文见 `references/h3_official_*.txt`。**编剧环节的对应责任**：△画面描述必须能无损填入六段结构——角色/场景定义有档案卡支撑（subject_definitions）、连续性锁点显式标注（retention_analysis）、动作链按"首帧锚→动作→结果反应"时间线展开（detailed_description）。用户明确要求时，编剧可代推六段提示词。
21. **画外音、运镜与剪切官方规范**——画外音推提示词时显式声明"对应人物嘴唇保持闭合"；运镜用官方词汇表（Push In/Pan/Truck/Tilt/Pedestal/Arc/Tracking/Static/Shake/POV/Roll + amplitude/speed，仅在有意义时写，自然语句嵌入）；剪切原则："剪切应引入新信息，仅距离/微角度变化优先用运镜"。
22. **单镜打斗只允许一对攻防**——实测多对手多目标编排=钢管砸错人、劈空气（模型分不清谁打谁）。一镜=1攻1防一交换；"闪避"必须给落点替代物（砍刀劈进木箱，入木三分），否则模型渲染成砍空气；多对手跨镜轮换，人数账以出场人物清单为准。
23. **恐惧/逃跑必须符合行为逻辑**——逃跑=转身没命狂奔（可摔倒、爬起、再跑），禁"跪地慢爬"（违背求生本能，实测观感怪异）；武器握姿写明（正手握刀、刀尖朝前），防模型自造反握；非自主掉落写"脱力/脱手"。
24. **载具场景必须视点锚定，防破窗歧义**——载具上的镜头须写明视点，并喂载具参考图；未描述破损时禁"水/火吞没门窗"类歧义（实测：窗未破浪却破窗而入），用"白浪糊满整面玻璃"等外表面效果；"撞开/冲撞"类动词仅用于撞击主体镜。补充：窗外有风暴的舱内戏必须正向锚定门窗完好（"舷窗紧闭、玻璃完好，雨水在玻璃外侧蜿蜒而下"），否则模型自行脑补破窗。
25. **身处载具内的视点禁"自见其身"（2026-09-12 实测·Ref2VA幻影船）**——甲板/舱内等"人在其中"的视点，把载具自身外观写进背景主体=召唤幻影载具（实测：甲板戏定义"海魂号船身在背景中可见"→生成对向大船冲来撞岸堤——从甲板物理上看不见自己脚下的船身）。视点锚只用"脚下与身边"元素（铆钉钢板/栏杆/系缆桩/信号灯/舱壁灯）；载具完整外观**只在外部大全景镜**呈现。同时：①相对运动必须有可见参照物（码头灯火后退），无参照物禁写"加速/前进/冲进"；②禁写"承接下一镜/handoff"类预告语；③推理提示词时风格必须钉死为剧集设定（本剧=live-action写实真人，勿被3D动画模板带偏）。
26. **subject_definitions 的外观描述必须与参考图严格一致，且必须存在（2026-09-14 两次实测）**。三种状态只有一种是错的：①文图冲突=换装穿帮（实测：提示词"工装"vs图"风衣"）；②完全不写外观=参考图缺失或权重弱时，模型按场景原型自由发挥（实测：删光外观后，船长+码头+斧头场景回退为工作服）。正确格式：外观描述**简短且与参考图逐项一致**（发型/服装/标志物），既兜底又强化；状态覆盖（湿透/受伤/手持物）照常写；外观变更流程不变（改图→同步文字→后续集数统一）。
27. **实体名称锁定（2026-09-17《凤凰男的豪门贤妻》项目沉淀，跨剧通用）**——字字动画按名称提取角色/场景/物品资产，同一实体的名称微差（别名/笔误/简繁/单复数）会被判定为**全新实体**，触发重复生成参考图，且新参考图与原参考图必有微小差异=形象漂移。规则：①每部剧开工前建立《资产名称锁定表》：主配角+龙套、常驻+单次场景、跨集道具全部登记唯一锁定名称；②剧本与分镜的**人物行、场景标题行、△画面描述、道具标注行**必须与锁定表一字不差，△段落主语禁用"他/她"（首次出现必须具名）；③源材料中的同名异写（笔误/别名，如"李蓉=成蓉=婆婆""顾恩雅=顾雅恩"）改编时统一为锁定名并登记修正清单；④新实体**先登记再使用**，未登记名称不得出现在上述结构字段；⑤角色**对白内**的口语称呼（妈/老公/宋总/乐乐）不参与资产提取，可自然使用；⑥同一空间的布景/状态变化用"场景名（状态）"标注，不立新名（如"顾家客厅（宴会布置）"），避免同一空间被拆成多个场景资产。

## 官方对齐要点（h3-prompt-writing，2026-09-12 核对）

- **描述时长必须匹配生成时长（4-15秒）**——与我们的 12 秒一致（12 秒在官方 4-15 秒范围内）。
- **每个细节必须可见或可闻**——与守则13同源，官方背书。
- **一致性要求（I2VA）**：人物身份/服装/颜色/关键物件/空间关系全程一致——与守则3/18同源。
- **画外音必须声明对应人物"嘴唇保持闭合"**——官方确认画外音错配是已知问题，与守则1同源，推提示词时须显式加入此声明。
- **运镜词汇表**：Zoom/Push/Pan/Truck/Tilt/Pedestal/Arc/Tracking/Static/Shake/POV/Roll + amplitude（small/large）+ speed（slow/fast），仅在有意义时写；以自然语句嵌入，不堆标签。
- **剪切原则**："剪切应引入主体/空间/状态/视角/时间的新信息；仅距离或微角度变化优先用运镜"。
- **抽象词警告**：少用 "cinematic / beautiful" 类抽象词，多用具体视觉听觉细节——我们的风格尾缀保留（实测无漂移），但△描述必须具体（守则13）。
- **画面内可见文字**：官方允许用英文双引号原文渲染（字幕/招牌/霓虹），但实测中文渲染不稳——默认仍走守则8（后期字幕），仅在接受风险时使用。
- **官方仓库无武打专项 skill**：8个风格技能（3D动画/纸艺/MV/广告等）+ 1个提示词技能；武打按通用动作规则覆盖，我们的守则10/17为实测补充，与官方不冲突。

## 标准流水线

1. 编剧按提示包+二十七守则产初稿（**逐镜标注镜型：AI 初标 → 编剧复核确认**；含高危镜头自查：新镜头类型/4人满员/手部道具/特写比例）
2. 生成验证 → 坏镜反馈 → 只重生成坏镜
3. 抽检制：每5集1集送分镜专家交叉审（或高危集定向送审）
4. 新规律 → 回填本文件守则区 → 全剧生效

## 重新实测的触发条件

新镜头类型首现（水下/爆炸/载具）、换模型或工具版本、开新剧第1集、连续3镜同类崩坏。其余一律流水线直产。

## 已知坑速查（症状→守则）

说话人错位→1｜人物崩坏/景别跳变→2｜位置漂移→3｜拖沓/慢动作失控→4｜手部怪→5/9｜动作温柔→10｜字幕变英文→8｜巨手→9｜内容稀→12｜"无血迹"类怪话→13｜转场靠猜→14｜人影畸变→15｜下身异常→16｜打斗拖沓/呆立挨打→17｜道具跨镜变样→18｜自造载具外观/大小景混镜→19｜砍空气/砸错人→22｜跪地爬逃/反握刀→23｜破窗而入→24｜同一角色/场景被拆成多个实体、参考图重复生成且形象不一致→27｜**举刀／逼近／悬停不接触被误判成动作镜→规范二·附判据**（无接触无受力⇒无攻防链，应为对白镜）
