# 故事核心方法论

## 一、写作红线（禁止触碰）

以下内容**绝对不能出现**在分镜剧本中。触碰即重写。

### 心理描写红线

| 禁止 | 原因 | 替换方式 |
|------|------|---------|
| 他意识到了什么 | 摄影机拍不到意识 | 他的手猛地停住 |
| 她内心涌起悲伤 | 摄影机拍不到内心 | 她咬紧了嘴唇，低下头 |
| 他领会到她的意思 | 摄影机拍不到领会 | 他放下了杯子，没有说话 |
| 一股愤怒油然而生 | 摄影机拍不到感受 | 他的拳头握紧，关节泛白 |
| （其实是在掩饰紧张） | 括号内容拍不到 | 直接写他手抖/目光游移 |

### 对白红线

| 禁止 | 原因 | 替换方式 |
|------|------|---------|
| 你知道吗，这件事很复杂... | 解释性台词，不像真人说话 | 用对话暗示，不解释 |
| 我们都知道这意味着什么 | 主题宣告，过于说教 | 让观众自己推断 |
| 因为我爱你，所以... | 直接解释动机 | 用行动代替说明 |
| 我这么做是因为... | 解释内心逻辑 | 对话只露冰山一角 |

### AI提示词红线（Step 4专项）

| 禁止 | 原因 |
|------|------|
| 写角色真实姓名（如"林冲"） | AI不认识中国古典人物名 |
| "漂亮"、"帅气"、"很酷" | 主观词AI无法理解 |
| "他感到震惊" | 情绪词，用具体表情替代 |
| 快速移动、剧烈扭转 | 越快越容易崩，动作要慢 |
| "镜头移动" | 模糊词，必须用具体术语 |

## 二、Want / Need / Arc 三元结构

每个主要角色必须建立三元结构，这是人物弧光的基础。

### 定义

**Want（外部目标）：** 角色以为自己想要的东西——故事的显性动力。
**Need（内在需要）：** 角色真正需要的东西——通常与 Want 相矛盾，是主题所在。
**Arc（弧光转变）：** 角色从 Want 到 Need 的认知转变路径。

### 三种弧光类型

**正向弧（Positive Arc）：** 角色最终获得 Need，放弃或超越 Want
- 示例：林冲 Want=活下去隐忍 / Need=清醒认识世道 / Arc=被逼到绝境后爆发杀伐

**负向弧（Negative Arc）：** 角色未能获得 Need，被 Want 所毁
- 示例：麦克白 Want=权力 / Need=内心安宁 / Arc=追逐权力最终失去一切

**平弧（Flat Arc）：** 角色持守内在信念，改变了世界而非自己
- 示例：英雄类主角，坚守正义改变腐败世界

### 写法

```
[角色名]
Want：[外部目标——角色公开追求的东西]
Need：[内在需要——角色实际缺乏的东西]
Arc：[起点状态] → [触发事件] → [关键转折] → [终点状态]
核心矛盾：Want 与 Need 的冲突点是什么
```

**示例：**
```
林冲
Want：安分守己，保护家人，继续当教头的好日子
Need：认清这个世道不会因为他的隐忍而放过他
Arc：委曲求全 → 一再受辱 → 草料场被火 → 绝望爆发 → 清醒复仇
核心矛盾：越是忍让，越是被欺凌。只有放弃Want，才能得到Need
```

## 三、双轨节奏

分镜不只是一条情节线，而是同时运行两条轨道。

### 外部节奏轨（情节事件轨）

可见的、发生的、摄影机能拍到的事件序列。

```
E01：草料场上任 → E02：差拨勒索 → E03：陆谦假装道歉 
→ E04：草料场失火 → E05：得知阴谋 → E05：复仇
```

特点：
- 事件有因果关系
- 冲突不断升级
- 每集有明确事件推进

### 内部节奏轨（情感状态轨）

不可见的、内在的、通过身体语言和行为表现出来的情感状态。

```
E01：压抑的接受 → E02：克制的愤怒 → E03：短暂的警觉消散
→ E04：绝望的恐惧 → E05：彻底的清醒爆发
```

特点：
- 情感状态与外部事件**错位**（不是事件发生时立即反应）
- 张弛交替（紧张→松弛→更紧张）
- 情感累积，某一刻总爆发

### 双轨设计原则

**张弛对比：** 外部节奏快时，内部节奏应该慢（给观众喘息）；外部节奏慢时，内部节奏应该紧（暗流涌动）

**错位产生张力：** 外部平静 + 内部紧绷 = 悬疑感；外部剧烈 + 内部冷静 = 强大感

**示例对比：**
```
❌ 平铺直叙（两轨同步）：
外部：差拨骂林冲，林冲愤怒
内部：林冲感到愤怒
→ 结果：平淡，无层次

✅ 双轨错位（两轨对立）：
外部：差拨大声辱骂，林冲沉默低头
内部：林冲手中的杯子捏得更紧，指节泛白
→ 结果：压抑的张力，观众感受到火山要爆发
```

## 四、开场钩子设计（首集/首镜必读）

15秒短剧的第一个镜头决定了用户是否继续看。必须在0-3秒内钩住观众。

### 七种钩子类型

**1. 视觉冲击钩（最直接）**
用一个强烈的视觉画面作为开场。
- 适合：动作/悬疑/爽剧类型
- 示例：大雪中的孤独身影，草料场漫天飞雪

**2. 情绪反差钩**
开场的情绪与类型预期完全相反。
- 适合：反转类型
- 示例：爽剧开场却极度压抑，观众好奇：主角怎么了？

**3. 悬念钩（问题钩）**
开场立刻提出一个问题，让观众想知道答案。
- 适合：悬疑/惊悚类型
- 示例：一具尸体，或一句意味深长的话

**4. 角色强度钩**
主角一出场就展示出极强的个人魅力或独特性格。
- 适合：英雄类/爽剧类型
- 示例：鲁智深倒拔垂杨柳，不需要解释直接展示实力

**5. 世界规则钩**
开场展示这个世界的独特规则或奇特设定。
- 适合：奇幻/科幻/历史类型
- 示例：水墨风格的朝堂，一开场就建立世界观

**6. 时间压力钩**
开场让观众感受到时间紧迫感。
- 适合：惊悚/动作类型
- 示例：字幕"距离处决还有24小时"

**7. 情感共鸣钩**
开场建立强烈的情感认同，让观众立刻投入角色。
- 适合：情感/治愈类型
- 示例：主角独自一人，孤独的背影，直接击中孤独感

### 开场钩子设计原则

- 钩子必须在前3秒内完成
- 钩子必须与整集的核心梗匹配
- 避免用旁白/字幕解释来建立钩子（用画面）
- 钩子设下的"疑问"必须在本集或后续集中有回答

## 五、戏剧动作 vs 物理动作

**戏剧动作（真正重要的）：** 角色用行为想达到的目标，他对另一个人做了什么。
**物理动作（表面的）：** 角色的身体动作，是戏剧动作的载体。

```
物理动作：林冲给差拨银子
戏剧动作：林冲在委屈妥协中保护自己

物理动作：差拨接过银子，继续骂
戏剧动作：差拨在享受权力，踩人立威
```

分镜写的是物理动作，但背后必须有清晰的戏剧动作。没有戏剧动作的物理动作是空镜。

## 六、对话的潜台词原则

好的对话从不直接说出角色真正想说的话。

**直白对话（差）：**
```
林冲：我现在非常愤怒，但我还不能行动。
```

**潜台词对话（好）：**
```
林冲（看着差拨，沉默片刻）：多谢大人关照。
（端起茶杯，低头饮茶）
```

观众听到的是"谢谢"，感受到的是"我记住你了"。

### 对话节奏三原则

1. **切入后期（Start late）：** 对话从最有戏剧张力的那一刻开始，删掉寒暄
2. **提前离开（End early）：** 在最意外或最有余味的那一刻切断对话
3. **话题转移即反击（非正面回应）：** 真实对话中，人们很少直接回答问题

- [ ] 核心梗2-4字能说清楚

- [ ] 双轨节奏有张弛对比（不是两轨同步）
- [ ] 开场钩子在0-3秒内设置完毕
- [ ] Character Bible 英文固定词组建立完毕
