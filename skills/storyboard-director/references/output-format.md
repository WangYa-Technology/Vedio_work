# 输出格式规范

## 平台路由决策

首先确认目标平台，两种模式输出格式完全不同：

| 平台 | 模式 | 核心特征 | 输出格式 |
|------|------|---------|---------|
| Seedance 2.0 / Runway | 首尾帧模式（A） | 需要首帧图+尾帧图，AI在两帧之间生成运动 | 时间轴Markdown |
| 巨日禄 / 可灵 Fusion | 融生视频模式（B） | 需要角色参考图，AI将参考图融入视频 | Excel三列表格 |

---

## 输出物清单

每次完成分镜，交付以下文件：

**模式 A（Seedance）：**
1. `[剧名]_剧本.md` — 完整△格式剧本
2. `[剧名]_素材清单.md` — 资产编号 + Midjourney生成提示词
3. `[剧名]_E[XX]_分镜.md` — 每集 Seedance 提示词（时间轴格式）

**模式 B（巨日禄）：**
1. `[剧名]_剧本.md` — 完整△格式剧本
2. `[剧名]_素材清单.md` — 资产编号 + 角色参考图生成提示词
3. `[剧名]_巨日禄_分镜表.xlsx` — 三列分镜表（叙事语言，非AI提示词）

## 防崩约束（所有资产提示词末尾必须加）

**中文版：**
```
人物结构正常，面部清晰不变形，五官稳定，比例自然，动作不僵硬，画面稳定不抖动
```

**英文版：**
```
normal body structure, face clearly visible without distortion, stable facial features, natural proportions, fluid motion, stable frame without flickering
```

| 图片3（场景） | S01 | [场景名]·场景参考 |
| 图片4（道具） | P01 | [道具名]（如需参考） |

## Seedance Prompt

[风格]，15秒，[画幅]，[整体氛围]

[镜头运动]，[画面描述（场景建立/人物引入）]，[感官氛围]

## 分镜脚本格式 — 模式 B（融生视频 / 巨日禄）

### 巨日禄 Excel 三列格式规范

**表格结构：**

| 列 | 列宽 | 内容 | 说明 |
|----|------|------|------|
| A：分镜编号 | 12 | 数字编号 | 如 1、2、3... |
| B：分镜描述 | 60 | 叙事语言描述 | **不是AI提示词，是导演语言** |
| C：台词 | 40 | 精确台词或"无" | 不可改写 |

**关键规则：**
- 集数分隔行：合并 A:C 三列，写"第N集"，14pt加粗
- 表头行：灰色填充，12pt加粗
- 分镜描述：**必须用叙事语言**，如"李明走进办公室，把辞职信放在桌上，表情坚定地看着王总"
- **禁止**在B列写AI提示词格式的内容（巨日禄平台自己处理提示词生成）

**分镜描述写法（模式B专用）：**

```
✅ 正确（叙事语言）：
分镜描述：李明走进昏暗的病房，停在床边，低头看着躺着的父亲，双手微微颤抖

❌ 错误（AI提示词语言）：
分镜描述：Chinese man in his 30s, medium shot, slow push in, melancholic atmosphere
```

**完整Excel输出示例：**

```
[合并行A:C] 第一集
[表头] 分镜编号 | 分镜描述 | 台词
1 | 沧州城外，大雪漫天。镜头从高空俯拍，草料场全景在漫天飞雪中隐约可见，四周荒无人烟。 | 无
2 | 镜头缓慢下降，林冲（三四十岁男子，穿着破旧棉袄，头戴毡笠）独自站在草料场中央，手持长枪，任由寒风吹动衣角，望向远方。 | 无
3 | 近景，林冲侧脸，眼神深邃，呼出一口白气，瞬间消散在风中。嘴角紧抿，藏着说不清的落寞。 | 林冲（os）：又是一年冬。

[合并行A:C] 第二集
1 | 差拨和富安走进草料场，差拨手持藤条，一脸傲慢地打量着林冲。富安站在身后，嘴角挂着轻蔑的笑。 | 差拨：哟，林教头，住得还舒坦吗？
2 | 林冲转过身，目光平静地看着差拨，缓慢地低下头。 | 林冲：劳大人关照。
```

### 集间衔接备注格式（模式B专用）

```markdown
## 集间衔接备注（[剧名] E[XX]）

**本集使用的角色参考图：**
- 主角：C01-F（[角色名]正面全身）
- 配角：C02-F（[配角名]正面全身，如有）

**上一集结束状态：**
- 角色：[位置 + 动作 + 情绪]
- 场景：[在哪里]
- 关键道具：[手里拿着什么/周围有什么]

**本集开场状态：**
- [如何自然接续上一集]

**下一集衔接点：**
- 本集结束时，[角色/场景状态]
- 为下一集预留的情感线索：[悬念/余韵]
```

## 巨日禄上传规则

**整本上传：** 一次上传整个 Excel 文件（所有集数）
**单集上传：** 上传到第二个合并单元格之前停止（只含第一集）

通常推荐**整本上传**，让平台规划整体节奏。

## Markdown 分镜卡片（聊天窗口预览）

在聊天窗口展示时，用以下格式：

```
---
**分镜 001** ｜ ⏱️ 5秒

**📽️ 画面描述：**
[中文叙事描述]

**🤖 AI提示词：**（仅模式A需要）
[英文提示词]

**💬 台词：**
[台词原文，或"无"]

---
```

分镜超过10个时，只展示前3个，其余说明见完整文件。

## 文件命名规范

```
[剧名]_剧本.md
[剧名]_素材清单.md
[剧名]_E01_分镜.md        ← 模式 A
[剧名]_E02_分镜.md
...
[剧名]_巨日禄_分镜表.xlsx  ← 模式 B（单个文件含所有集）
```

示例：
```
林教头风雪山神庙_剧本.md
林教头风雪山神庙_素材清单.md
林教头风雪山神庙_E01_分镜.md    ← Seedance模式
林教头风雪山神庙_巨日禄_分镜表.xlsx  ← 巨日禄模式
```
