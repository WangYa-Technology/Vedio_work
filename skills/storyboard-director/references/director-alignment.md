# 导演定调方法论

## 一、六维定调系统

**导演定调的目的：** 在写第一个镜头之前，让所有视觉/听觉/节奏的选择都指向同一个方向。六维定调完成后，每个分镜决策都有了标准。

---

### 维度 1：情绪维度

**定义：** 这部剧想让观众离开屏幕时残留在身体里的情绪。

| 情绪方向 | 关键词 | 典型色调 | 典型运镜 |
|---------|------|---------|---------|
| 压抑→爆发 | oppressive, suffocating, explosive | 灰白→鲜红 | 推镜为主，最后快剪 |
| 悲怆孤独 | melancholic, desolate, lonely | 冷蓝，淡墨 | 拉镜，空镜，环绕 |
| 热血燃爽 | epic, triumphant, exhilarating | 金色，高对比 | 快剪，升镜，低角仰拍 |
| 温暖治愈 | warm, tender, heartwarming | 暖黄，低饱和 | 跟拍，缓推，特写 |
| 悬疑紧张 | eerie, suspenseful, tense | 暗绿，冷蓝 | 手持晃动，希区柯克变焦 |
| 史诗宏大 | awestruck, epic, overwhelming | 金色，大对比 | 升镜，航拍，一镜到底 |

---

### 维度 2：类型维度

**定义：** 镜头语言风格参照的类型范本。

| 类型 | 镜头语言特征 | 典型参照 |
|------|------------|---------|
| 武侠/历史 | 长镜头追拍，构图讲究留白，用雨雪等自然元素强化情绪 | 《卧虎藏龙》 |
| 现代都市 | 手持摄影机，切换快，特写多，对话快速剪辑 | 《无间道》 |
| 修仙/奇幻 | 慢动作+升格，大量体积光，广角夸张透视 | 《陈情令》 |
| 惊悚/悬疑 | 不稳定构图，倾斜镜头，zoom in强调，跳切 | 《黑镜》 |
| 治愈/情感 | 自然光，少切换，面部特写，呼吸感节奏 | 《请回答1988》 |
| 动作/打斗 | 摄影机跟随移动，连续长镜，打击感快剪 | 《疾速追杀》 |
| 水墨/古风 | 留白构图，淡入淡出，慢推，水墨晕染效果 | 《大鱼海棠》 |

---

### 维度 3：动作维度

**定义：** 打斗、运动、动作场景的处理方式。

| 处理方式 | 特征 | 适合 |
|---------|------|------|
| 武术美学式 | 慢动作展示技巧，构图优先，节奏感强 | 武侠、功夫片 |
| 实战暴力式 | 快速凌乱，手持晃动，突发性 | 现代动作、惊悚 |
| 舞蹈编排式 | 动作如舞蹈，音乐节奏同步 | 修仙、奇幻 |
| 极简克制式 | 最小化动作展示，张力在心理层面 | 悬疑、文艺 |

---

### 维度 4：题材维度

**定义：** 历史/现代/奇幻/写实的视觉规范差异。

| 题材 | 视觉规范 | 禁止事项 |
|------|---------|---------|
| 历史古装 | 水墨感/电影感，准确的服道化，古典构图 | 现代感构图，饱和色滤镜 |
| 现代都市 | 霓虹感，玻璃/钢铁材质，高对比 | 古典构图，大留白 |
| 古典修仙 | 飘逸感，仙雾，神光，大留白 | 写实质感，脏底光 |
| 写实现代 | 自然光，手持，无明显色彩处理 | 过度调色，戏剧化布光 |

---

### 维度 5：形式维度

**定义：** 剪辑节奏和镜头形式的基本策略。

| 形式 | 平均镜头时长 | 特征 | 适合阶段 |
|------|------------|------|---------|
| 长镜头派 | 5-8秒/镜 | 沉浸感强，节奏缓慢，情感积累 | 建立期、情感期 |
| 快剪派 | 1-2秒/镜 | 节奏紧张，信息密度高，刺激感 | 高潮期、动作期 |
| 混合派 | 随情绪切换 | 长镜建立情绪→快剪爆发，对比效果强 | 大多数情况 |
| 一镜到底 | 整集一镜 | 沉浸感极强，制作难度高 | 特殊集，高光时刻 |

**15秒短剧推荐：混合派**
- 0-3秒：长镜建立氛围（3-5秒/镜）
- 3-9秒：递进推进（2-4秒/镜）
- 9-12秒：高潮快剪（1-2秒/镜）
- 12-15秒：慢镜收尾（3-4秒/镜）

---

### 维度 6：社会视角维度

**定义：** 故事站在谁的立场，谁是观众的情感锚点。

| 视角 | 含义 | 影响分镜的方式 |
|------|------|--------------|
| 受害者视角 | 与受压迫角色同情 | 镜头紧贴主角，反派镜头冷峻俯拍 |
| 观察者视角 | 保持距离，呈现多方 | 更多中景/远景，少主观镜头 |
| 多元视角 | 每个角色都有逻辑 | 各角色都有特写，避免脸谱化 |
| 历史反思视角 | 宏观看待事件 | 大量空镜，个人命运与宏大背景对比 |

## 二、六维定调输出模板

完成定调后必须输出以下格式，作为后续所有分镜决策的标准：

```
## 导演定调表

| 维度 | 方向 | 关键词 |
|------|------|--------|
| 情绪 | [整体情绪走向] | [3个关键词] |
| 类型 | [参照类型] | [镜头语言风格] |
| 动作 | [动作处理方式] | [节奏特征] |
| 题材 | [历史/现代/奇幻] | [视觉规范关键词] |
| 形式 | [长镜/快剪/混合] | [平均镜头时长] |
| 社会视角 | [谁的立场] | [观众情感锚点] |

视觉关键词（全剧统一）：[词1] + [词2] + [词3]
音响关键词：[配乐类型] + [标志性音效]
```

## 三、意象体系设计

### 什么是意象体系

意象体系是贯穿全剧的视觉符号系统。选择1-3个反复出现的视觉元素，每次出现都在强化主题或角色状态。

### 意象设计原则

1. **具体可拍摄：** 必须是摄影机能拍到的实物（不能是"孤独"，可以是"一个空椅子"）
2. **可以演变：** 同一个意象在剧中有开始、发展、终结的含义变化
3. **与主题相连：** 意象的演变轨迹就是主题的表达轨迹
4. **不过度解释：** 让观众自己感受意象含义，不要通过对白解释

### 意象设计模板

```
### 视觉母题

**[意象1]：[具体物品]**
- 第一次出现：E[X] — [含义]
- 发展变化：E[X] — [含义变化]
- 最终状态：E[X] — [含义升华]
- 象征：[主题关联]

**[意象2]：[具体物品]**
...
```

### 经典意象案例参考

| 意象 | 作品 | 演变轨迹 |
|------|------|---------|
| 风雪 | 林冲 | E1自然环境→E3命运暗示→E5覆盖鲜血 |
| 长枪 | 林冲 | E1看守工具→E3负担→E5复仇利器 |
| 酒葫芦 | 林冲 | E1逃避→E3最后一口→E5彻底放下 |
| 围巾 | 现代爱情 | E1相送→E3遗失→E8重新找到 |
| 空椅子 | 等待/缺席 | 人在时→人离去→空椅暗示结局 |

## 四、空间象征设计

空间本身就有象征意义，分镜设计要利用空间语言。

| 空间状态 | 象征含义 | 运用方式 |
|---------|---------|---------|
| 封闭→开阔 | 从压抑到自由 | 监狱/小房间切到广阔草原 |
| 高处→低处 | 从优势到弱势 | 俯拍→仰拍，强化权力关系 |
| 明亮→黑暗 | 从安全到危险 | 光线渐暗，代替旁白解释风险 |
| 拥挤→空旷 | 从连接到孤立 | 人群散去，主角独自留下 |
| 室内→室外 | 从私密到公开/从保护到暴露 | 推门而出，改变角色状态 |

## 五、音响设计定调

### 三层音响结构

**层1：配乐（情绪基调）**
- 全剧主题曲：几个乐器音色定义整体风格
- 角色主题：每个主要角色有专属的配器或旋律
- 情境变奏：同一主题根据情绪变化编曲

**层2：音效（具体事件）**
- 环境音：建立空间感（风声、市场声、雨声）
- 动作音：击打、脚步、开门等
- 标志性音效：某个声音反复出现成为符号（如刀出鞘声）

**层3：对白（信息/情感）**
- 极简对白：对白密度低，每句话都有分量
- 潜台词密集：大量双关，话中有话
- 旁白/OS：角色内心，但要克制使用

### 音响与画面的关系

| 关系类型 | 效果 | 使用场景 |
|---------|------|---------|
| 同步（画面有，声音有） | 真实感，正常节奏 | 日常场景 |
| 对位（画面安静，声音紧张） | 悬疑，不安感 | 暗流涌动时 |
| 声音先行（声音来了，画面跟上） | 紧张感，预期建立 | 动作戏前 |
| 无声（突然静音） | 震惊，强调 | 关键转折 |
| 音效代替画面 | 留白，想象空间 | 不宜直接展示的内容 |

## 六、类型库快速参考

### 水墨武侠

镜头语言：大留白构图，缓慢推镜，环绕展示孤独身影
色彩：灰白墨黑，局部冷蓝，鲜血红作点缀
音效：二胡/古筝，风声，雪声，铁器碰撞
标志运镜：高空俯拍下降→中景推近→面部特写→拉远背影

### 现代都市爽剧

镜头语言：手持晃动，快切，特写面部情绪，低角仰拍
色彩：霓虹蓝橙，高对比，暗部深沉
音效：电子节拍，城市噪音，突然寂静
标志运镜：特写推近→反应切换→动作快剪

### 古装修仙

镜头语言：升格慢动作，体积光充溢，广角夸张，留白
色彩：金白光，仙雾，偶尔饱和色特效
音效：古风管弦，法器声，玄妙空鸣
标志运镜：低角仰拍→慢速环绕→大全景建立世界观

### 悬疑惊悚

镜头语言：不稳定构图（倾斜），希区柯克变焦，手持，跳切
色彩：去饱和，冷绿蓝，高光偏白
音效：低频震动，突发音效刺激，长时静默
标志运镜：推近→突然静止→反向拉远（让人不舒适）
