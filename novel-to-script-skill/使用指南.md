# 剧本锻造 Script Forging — 使用指南

**作者**：摇摆时间线（数字影像工程师 / 影视流程管理 / AI 影视应用）

**版本**：v0.4.6（2026-06-05）

---

## 这是什么

**剧本锻造（Script Forging）** 是一个 AI Skill，专门把成熟故事转化为可拍摄执行的影视剧本、分镜方案和数字资产清单。

它不是"给人看"的影视开发分析报告——那是[叙事转译 Skill](https://github.com/zhlmi/narrative-to-screen-reader) 的工作。剧本锻造的所有产物服务于**剧本生成和拍摄执行**。

一句话定位：

> 把一个好故事，锻造成能拍、能演、能交给 AI 继续生成的剧本和分镜。

---

## 与叙事转译 Skill 的关系

两个 Skill **不是递进关系，而是具有回路的相互辅助关系**：

| | 叙事转译 | 剧本锻造 |
|:--|:--|:--|
| **偏向** | 影视化开发方向 | 影视前期执行方向 |
| **核心产出** | 读本 · 分析 · 定位 | 剧本 · 分镜 · 资产 |
| **一句话** | 做对的事（方向） | 把事做对（执行） |

**典型协作流程**：故事原文 → 叙事转译快速诊断 → A 级后交给剧本锻造 → 剧本定稿后回叙事转译做演员读本/导演视听读本。

![协作工作流流程图](https://raw.githubusercontent.com/zhlmi/script-forging/main/script-forging-workflow.png)

> 也可查看[可交互的 HTML 版流程图](https://github.com/zhlmi/script-forging/blob/main/script-forging-workflow.html)，支持缩放和平移。

*流程图说明*：
- 故事原文先经叙事转译快速诊断（A/B/C/D 评级）
- B/C/D 级 → 编剧改编读本补强 → 重新评级
- A 级 → 两条路线可选：传统影视开发（叙事转译）或 AI 执行工作流（剧本锻造）
- 两个 Skill 共享"AI 剧本化提示包"
- 剧本锻造产出的定稿剧本，可回路到叙事转译生成演员读本、导演视听读本

## 核心流程

```
故事原文 → [Step 1 专业形态建议] → [Step 2 最小确认]
         → [Step 3 剧本化提示包] → 🔴 CHECKPOINT
         → [Step 4 分场大纲] → 🔴 CHECKPOINT
         → [Step 5 标准剧本 ↔ 逐稿自检] → 🔴 CHECKPOINT
         → [Step 6 分镜表]（可选）
         → [Step 7 数字资产清单]（可选）
```

每一步都有对应的 **CHECKPOINT（检查点）**，在关键节点暂停等待你的确认，确保不跑偏。

## 支持的输入

剧本锻造接受以下类型的输入（前提是**故事已经成熟**——有明确主角、核心冲突、结局和足够场景支撑）：

| 输入类型 | 说明 |
|:--|:--|
| 短篇小说 | 最理想的输入类型 |
| 中长篇片段 | 标注不确定信息，不擅自补全 |
| 剧情大纲 / 故事梗概 | 做开发诊断，找缺口再生成 |
| 长会话角色扮演记录 | 先整理主线，合并重复推进后使用 |
| 已有剧本初稿 | 进入修订线或分镜执行线 |
| 互动 / 游戏叙事文本 | 识别主路径和分支节点后使用 |

**不支持的输入**：
- 少于 500 字的极短文本（骨架太薄，不足以剧本化）
- 只有概念没有故事（缺少人物、冲突、场景）
- 纯情绪堆砌或概念宣言（没有叙事骨架）

## 支持的输出

### Step 1：专业形态建议

AI 判断故事最适合哪种影视形态，给出推荐强度和理由：

- 长片（45-60 场，多阶段人物关系推进）
- 中短片（核心事件集中，少量场景完成主题）
- 剧集（多人物、多支线、世界观可持续展开）
- 短剧 / 微短剧（高频冲突、密集钩子、强反转）
- 实验影像 / 艺术短片（事件少，意象是核心表达）

### Step 3：剧本化提示包（强制步骤）

这是写剧本之前的**控制层文档**，包含 13 个字段：

1. 项目基本参数（类型、形态、基调、目标格式）
2. 结构比例建议（幕段划分、场次占比、戏剧功能）
3. 原文优先级声明（冲突以谁为准）
4. 不可改核心（人物关系、结局、关键动机、叙事气质）
5. 必须保留场景（位置、戏剧功能、可压缩程度）
6. 必须保留台词 / 动作（是否允许改写）
7. 必须保留物件 / 母题（首次出现、发展、回收方式）
8. 可调整范围（合并、压缩、内心戏转动作）
9. 禁止行为清单（明确不能做什么）
10. 剧本格式规则（场景标题、对白、微信格式）
11. 分场大纲规则（每场必写字段）
12. 剧本自检清单（生成后逐条检查）
13. 最终执行 Prompt（可复制给另一个 AI 执行）

### Step 4：分场大纲

每场包含 10 个字段的施工图：

- 场号、场景标题、出场人物
- 本场戏剧任务、开始状态、核心动作
- 情绪转折、必保台词/物件
- 场尾钩子 / 转场逻辑
- 备注（可压缩/不可压缩/可合并）

### Step 5：标准剧本 + 自检报告

- 标准剧本一稿 → 剧本一稿自检报告 → 二稿 → 二稿自检报告 → …
- 每稿自检分为三个级别：**致命问题**（必须改）、**高优先级**（>3 项建议改）、**可优化**（可选）
- 格式统一：场标题 `## 场 X｜内/外景 地点 - 时间`，对白人物名单独加粗，微信用引用格式

### Step 6：分镜表（可选执行层）

四个层级可选：

| 层级 | 名称 | 适用场景 |
|:--|:--|:--|
| A | 关键分镜表 | 概念开发、视觉骨架、AI 方向初稿 |
| B | 场级分镜表 | 拍摄执行初稿 |
| C | 逐镜头精细分镜 | 正式拍摄、AI 视频逐镜生成 |
| D | 自定义范围 | 指定场次 / 镜头密度 |

逐镜头精细分镜额外支持：镜头目的、起幅、落幅、主体运动、画面连续性、AI 视频提示词、负面提示词。

### Step 7：数字资产清单（资产固化层）

五类资产，用于后续 AI 视觉生成、拍摄筹备、连续性管理：

1. **角色资产**（资产 ID、外观连续性、关系绑定、出场场次）
2. **场景资产**（空间功能、视觉关键词、连续性要求）
3. **道具 / 物件资产**（叙事功能、外观状态、连续性变化）
4. **母题 / 意象资产**（主题功能、变化路径、禁止误用）
5. **服装 / 妆发 / 状态连续性**（按阶段锁定、变化原因）

资产采用"稳定偏好"设计：每个重要资产分配稳定 ID，主名称不漂移，版本状态明确，支持二稿/三稿后的变更记录而非重建。

## 怎么使用

### 推荐用法

**最简路径**（只想快速拿到剧本）：

```
"帮我把这篇小说锻造成标准剧本。"
```

Skill 会自动完成：形态判断 → 提示包生成 → 等待确认 → 分场大纲 → 等待确认 → 剧本正文 → 自检报告。

**完整路径**（从故事到可拍摄的全套方案）：

```
"帮我做完整锻造：从这篇小说到剧本、分镜、资产清单，全流程。"
```

Skill 会在每个 CHECKPOINT 暂停等你确认，确保每一步都正确。

**只做某个环节**：

```
"只帮我做分场大纲"       → 跳过提示包生成，直接用故事出分场
"帮我修订这个剧本的二稿"   → 进入修订线，基于自检报告改
"把这个定稿剧本拆成分镜"   → 进入分镜执行线
"生成这个项目的数字资产清单" → 进入资产固化线
```

**补强后再锻造**（故事还不够成熟时）：

```
"先用叙事转译做快速诊断，看看这篇故事到什么水平了。"
```
如果诊断结果为 B/C/D，先做编剧改编读本补强；达到 A 级后再交给剧本锻造。

**与叙事转译配合使用的完整工作流**：

```
"帮我把这个故事走完整流程：先叙事转译诊断 → A 级后进剧本锻造 → 剧本定稿后回叙事转译出演员读本和导演视听读本。"
```

### 不推荐的用法

- ❌ **直接把概念丢进来**——"我想写一个关于爱情的故事"——没有人物、冲突、场景，Skill 无法工作
- ❌ **跳过 CHECKPOINT 催着出**——"别停了，一口气全出来"——每步确认是防止跑偏的唯一机制，跳过的代价是整稿重来
- ❌ **要求添加狗血情节**——"加点车祸怎么样？"——Skill 明确禁止无依据新增狗血冲突
- ❌ **让它帮你写故事**——这不是故事生成器，是**成熟故事的剧本锻造器**
- ❌ **把分镜当最终导演方案**——分镜是执行参考，不是取代导演创作

## 输出文件结构

所有产物保存在 `项目名/` 目录下：

```
项目名/
├── 项目名_剧本化提示包.md          # Step 3：控制层文档
├── 项目名_分场大纲.md              # Step 4：分场施工图
├── 项目名_标准剧本一稿.md          # Step 5：剧本正文
├── 项目名_剧本一稿自检报告.md      # Step 5：同步自检
├── 项目名_标准剧本二稿.md          # Step 5：修订版（如有）
├── 项目名_剧本二稿自检报告.md      # Step 5：修订自检（如有）
├── 项目名_关键分镜表.md            # Step 6：A 层级
├── 项目名_场级分镜表.md            # Step 6：B 层级
├── 项目名_第X场逐镜头分镜.md       # Step 6：C 层级（单场）
├── 项目名_第X集逐镜头分镜_批次01.md # Step 6：C 层级（剧集分批）
└── 项目名_数字资产清单.md          # Step 7：角色/场景/道具/母题/服装
```
