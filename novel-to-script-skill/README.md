# 剧本锻造 Script Forging

> 把一个好故事，锻造成能拍、能演、能交给 AI 继续生成的剧本和分镜。

**作者**：摇摆时间线（数字影像工程师 / 影视流程管理 / AI 影视应用）

---

## 这是什么

**剧本锻造**是一个 AI Skill——不是魔法棒，不是"一键生成好莱坞剧本"的营销噱头。它是一个经过精密设计的**工作流引擎**，把成熟故事一步一步转化为标准影视剧本、分镜方案和数字资产清单。

它的每一稿都在你眼皮底下完成，每一步都等你拍板才往下走。你始终是那个喊"咔"的人。

> AI 负责锻造，你负责判断。

---

## 它和你已有的那个 Skill 是什么关系

如果你已经用过[叙事转译 Skill](https://github.com/zhlmi/narrative-to-screen-reader)，你大概猜到了——这两个 Skill 是搭档。

| | 叙事转译 | 剧本锻造 |
|:--|:--|:--|
| **擅长的事** | 读故事、分析人物、写读本 | 写剧本、拆分镜、造资产 |
| **回答的问题** | "这个故事能拍吗？怎么拍最好？" | "那就拍吧——场场戏怎么拍？" |
| **给你看的东西** | 开发读本、演员读本、制片摘要 | 剧本正文、分镜表、道具/场景清单 |
| **偏向** | 影视化开发方向 | 影视前期执行方向 |

简单粗暴地讲：**叙事转译告诉你方向对不对，剧本锻造帮你把事做出来。** 而且它不是单向流动——剧本定稿后可以回到叙事转译，基于定稿生成演员读本和导演视听读本。两个 Skill 是**回路**，不是流水线。

## 流程一览

![剧本锻造 × 叙事转译 协作工作流](https://raw.githubusercontent.com/zhlmi/script-forging/main/script-forging-workflow.png)

> 点击查看[可交互 HTML 版](https://github.com/zhlmi/script-forging/blob/main/script-forging-workflow.html)，支持缩放平移。

剧本锻造自身的核心流程：

```
故事原文
  → 专业形态判断（长片？短片？还是更适合短剧？）
  → 剧本化提示包（写剧本之前的控制层文档）
  → 🔴 等你确认
  → 分场大纲（每一场的施工图）
  → 🔴 等你确认
  → 标准剧本一稿 → 自检报告
  → 标准剧本二稿 → 自检报告（如果有致命问题或高优项≥3个）
  → 🔴 等你确认
  → 分镜表（可选，关键分镜 / 场级 / 逐镜头）
  → 数字资产清单（可选，角色/场景/道具/母题/服装）
```

每一步都有 **🔴 CHECKPOINT**——不是因为 AI 笨，是因为**你必须决定方向**。AI 不能替你判断"这个结局对不对味"。

---

## 支持的输入

- ✅ 短篇小说（最理想）
- ✅ 中长篇片段（不确定的会标注）
- ✅ 剧情大纲 / 故事梗概（会先找缺口）
- ✅ 长会话角色扮演记录（先整理主线再使用）
- ✅ 已有剧本初稿（进入修订线或分镜线）
- ✅ 互动 / 游戏叙事文本

**不支持的**：少于 500 字的极短文本、只有概念没有故事、纯情绪堆砌。

---

## 输出的东西

| 模块 | 是什么 | 什么时候用 |
|:--|:--|:--|
| 专业形态建议 | AI 判断你的故事更适合长片/短片/剧集/短剧 | 决定拍什么之前 |
| 剧本化提示包 | 13 字段控制层文档，定义"什么不能改、什么必须保" | 写剧本之前，**必做** |
| 分场大纲 | 每场 10 个字段的施工图 | 写剧本正文之前 |
| 标准剧本 | 多稿迭代 + 每稿同步自检报告 | 核心产出 |
| 分镜表 | 关键分镜 / 场级 / 逐镜头精细分镜（可选） | 剧本确认后 |
| 数字资产清单 | 角色 / 场景 / 道具 / 母题 / 服装状态（可选） | AI 视觉生成、拍摄筹备 |

详细说明见[使用指南](https://github.com/zhlmi/script-forging/blob/main/%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97.md)。

## 怎么用

### 最偷懒的方式

```
"帮我把这篇小说锻造成标准剧本。"
```

它会自己走完：形态判断 → 提示包 → 等你确认 → 分场大纲 → 等你确认 → 剧本正文 → 自检报告。

### 只要一个环节

```
"只帮我做分场大纲，不要写剧本正文。"
"帮我把这个定稿剧本拆成逐镜头分镜，只拆第 3 场和第 8 场。"
"给这个项目生成数字资产清单。"
```

### 故事还不够成熟？

```
"先用叙事转译诊断一下这篇故事，看看能到几级。"
```

B/C/D 级会建议先做编剧改编读本补强，达到 A 级后再交给剧本锻造。

### 完整全套

```
"走全流程：叙事转译诊断 → 锻造剧本/分镜/资产 → 回到叙事转译出演员读本和导演读本。"
```

### 不要这样用

- ❌ 丢一个概念进来——"我想写一个关于背叛的故事"——回去先想好谁背叛了谁、为什么、结果怎样
- ❌ 跳过所有 CHECKPOINT 催着 AI 一路出到底——快是快了，偏了更惨
- ❌ "能不能加点车祸？"——不能。无依据的狗血情节是明确禁止的
- ❌ 把分镜表当最终导演方案甩给剧组——分镜是执行参考，不是导演替身
