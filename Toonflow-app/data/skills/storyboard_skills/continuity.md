# 集间连续性规则

## 两种模式的连续性逻辑差异

连续性的核心问题是：**下一集如何知道上一集结束在哪里？**

两种模式的回答完全不同。

---

## 模式 A：首尾帧模式（Seedance 2.0 / Runway）

### 原理

AI在**首帧图**和**尾帧图**之间生成运动。下一集的首帧必须与上一集的尾帧**画面内容接近**，否则剪辑时会出现跳变。

### 尾帧描述格式（必须详细，缺项会导致连续性断裂）

```
## 尾帧描述

**场景：** [当前在哪里，具体位置]
**主体：** [角色名] + [服装关键词] + [具体姿势/动作]
**背景：** [背景元素，深度，远处有什么]
**光线：** [光线方向] + [光线质感] + [色调]
**构图：** [角色在画面的位置] + [构图方式]
**情绪：** [人物情绪状态]
**用途：** 作为 E[XX+1] 的首帧参考
```

**✅ 好的尾帧描述：**
```
## 尾帧描述

**场景：** 山神庙内，神像前的火堆旁
**主体：** 林冲，破旧棉袄+毡笠，手握花枪横在膝头，侧坐，头微低，闭目
**背景：** 破败神像，蛛网，昏暗庙墙，火光在墙上投下摇曳的影子
**光线：** 火焰暖光从下方打亮脸部下半侧，四周深暗，侧逆光轮廓
**构图：** 人物居中偏左，火堆在右下角，整体偏暗
**情绪：** 疲惫，压抑，隐忍，警觉
**用途：** 作为 E04 的首帧参考
```

**❌ 不够用的尾帧描述：**
```
林冲在山神庙里。
```

### 集间衔接操作

**E01 → E02 衔接：**
```
E01 尾帧：[描述]
↓
生成 E01 尾帧图（这张图既是 E01 的尾帧，也是 E02 的首帧参考）
↓
E02 Seedance 上传：@图片1 = E02首帧（内容≈E01尾帧）, @图片2 = E02尾帧
```

**Seedance 续拍语法（E02起）：**
```
将@视频1延长15s

延续前视频的风格和主体：
0-Xs：[新内容描述]，与前视频无缝衔接
...
【要求】保持角色一致性，动作连贯流畅
【参考】@视频1 上一集视频，@图片1 新的尾帧参考
```

## 模式 B：融生视频模式（巨日禄 / 可灵 Fusion）

### 原理

AI将参考图**融合**进生成的视频，而非在两个关键帧之间插值。连续性依靠**角色参考图的一致性**，而非首尾帧对应。

只要每集使用相同的角色参考图，AI就能保持角色外观一致。场景不需要严格对应，只需在提示词中描述过渡即可。

### 集间衔接备注格式

```
## 集间衔接备注

**上一集结束状态：**
- 角色：[位置 + 动作 + 情绪]
- 场景：[在哪里]
- 关键道具：[手里拿着什么/周围有什么]

**本集开场状态：**
- [如何自然接续上一集]

**下一集衔接点：**
- 本集结束时，[角色/场景状态]
- 为下一集预留的情感线索：[悬念/余韵]
```

**示例：**
```
## 集间衔接备注

**上一集结束状态：**
- 角色：林冲手握花枪，侧身贴在庙门缝边，屏息偷听
- 场景：山神庙内，火堆将灭
- 关键道具：大石头抵着庙门

**本集开场状态：**
- 林冲听清陆谦阴谋，浑身一震，眼中怒火燃起
- 场景连续：同一山神庙内

**下一集衔接点：**
- 本集结束：林冲提枪踹门，门外火光映红门缝
- 为 E05 预留：门外三人不知杀机已至的短暂错愕
```

### 角色参考图一致性规则

融生模式中，**同一角色的参考图必须贯穿所有集**。不要在中途换图。

```
C01-F 林冲正面全身参考图 → 在 E01-E05 所有集都用这张
C01-S 林冲3/4侧面参考图 → 在需要侧面镜头的集使用
```

如果角色在剧中有服装变化（如古装→现代），必须分别生成：
```
C01-F-modern 现代服装正面
C01-F-ancient 古装正面
```
并在对应集中使用对应版本。

## 两种模式连续性对比

| 维度 | 首尾帧模式（A） | 融生视频模式（B） |
|------|---------------|----------------|
| 连续性依赖 | 首帧图/尾帧图画面内容 | 角色参考图一致性 |
| 断裂风险 | 首尾帧内容不匹配 → 画面跳变 | 换了不同的角色参考图 → 角色"换脸" |
| 修复方式 | 重新生成匹配的首帧图 | 换回正确的角色参考图 |
| 跨场景处理 | 需要生成新场景的首帧图 | 在提示词中描述场景变化即可 |
| 记录负担 | 高（每集需详细尾帧描述） | 低（记录衔接状态即可） |

## 集间连续性检查清单

**模式 A（首尾帧）：**
- [ ] 本集尾帧描述已填写（6个维度齐全）
- [ ] 下一集首帧图将基于本集尾帧生成
- [ ] 角色服装/道具在连续集中一致

**模式 B（融生视频）：**
- [ ] 集间衔接备注已填写（上一集结束/本集开场/下集衔接点）
- [ ] 本集使用的角色参考图 ID 已记录
- [ ] 如有服装变化，已生成对应参考图版本
- [ ] 巨日禄 Excel 已更新对应集的分镜描述
