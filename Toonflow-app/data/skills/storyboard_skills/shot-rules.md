# 分镜拆解规则

## 标准剧本格式（△格式）

**每集格式模板：**

```
第X集
X-X [日/夜] [内/外] [场景名称]
道具：[道具1]、[道具2]
出场人物：[角色1]、[角色2]

△ 【空镜】[开场氛围镜头，详细的画面、运镜、光影、感官描述]
△ [镜头2：具体运镜 + 画面 + 动作 + 感官细节]
△ [镜头3：继续推进]
角色名（os）：[内心独白/旁白]
△ [反应镜头：面部表情 + 肢体语言]
角色名：[对白]
△ [动作序列：用 → 连接连续动作]
【字幕：xxx】
△ 【闪回】[闪回场景描述]
[闪回镜头]
【闪回结束】
△ [回到现实]
角色名（vo）：[画外音，人物不在画面中]
△ 【空镜】[结尾氛围镜头]
【字幕：xxx】
```

**规则：每个镜头必须以 `△ `（三角形+空格）开头。**

---

## 核心原则：15秒单元制

每集约15秒，按情节类型决定镜头数量：

| 集数类型 | 镜头数量 | 节奏 | 适用场景 |
|---------|---------|------|---------|
| 情绪/对白集 | 3-4个镜头 | 4-5秒/镜 | 内心戏、对话、情感积累 |
| 动作/打斗集 | 5-7个镜头 | 2-3秒/镜 | 战斗、追逐、高潮 |
| 蒙太奇/闪回集 | 6-8个镜头 | 2秒/镜 | 快速剪辑、回忆 |

**每集情绪弧线（必须有起伏）：**
```
0-3秒：建立情绪/氛围
   ↓
3-9秒：情绪上升/冲突发展
   ↓
9-12秒：情绪高潮/关键揭示
   ↓
12-15秒：情绪释放/悬念收尾
```

## 镜头运动术语（必须使用具体术语）

| 运镜 | 中文 | 用途 | 示例写法 |
|------|------|------|---------|
| Push In | 推镜头/缓慢推近/急速推进 | 强调情绪，聚焦主体 | `镜头缓慢推近至林冲面部特写` |
| Pull Out | 拉镜头/逐渐拉远 | 展现环境，营造疏离感 | `镜头拉远，展示茫茫雪原` |
| Pan | 左摇/右摇 | 展示场景全貌 | `镜头从左摇至右，展现废墟` |
| Truck | 移镜头/横移 | 跟随横向移动 | `移镜头跟随奔跑的身影` |
| Follow | 跟镜头/跟拍 | 跟随主体移动 | `跟拍林冲行走，脚步沉重` |
| Orbit | 环绕镜头/360度旋转 | 360度展示主体 | `镜头环绕林冲缓慢旋转270度` |
| Crane | 升降镜头/俯冲/拉升 | 俯瞰或从低往高 | `高空俯拍后缓慢下降前推` |
| Hitchcock | 希区柯克变焦 | 背景压缩，压迫感 | `希区柯克变焦，背景压缩` |
| One Shot | 一镜到底 | 长镜头不切换 | `一镜到底跟随人物` |
| Handheld | 手持晃动 | 纪实感，紧张感 | `手持摄像机晃动感` |

**❌ 不能写：** "镜头移动"、"镜头变化"、"画面切换"
**✅ 必须写：** "推镜头"、"环绕镜头"、"特写跟拍"

## 景别术语

| 景别 | 画面范围 | 用途 |
|------|---------|------|
| 远景 | 环境全景，人物很小 | 建立场景，展现氛围 |
| 全景 | 人物全身 | 展现动作，空间关系 |
| 中景 | 人物腰部以上 | 常用对话场景 |
| 近景 | 人物胸部以上 | 情感交流 |
| 特写 | 面部或细节 | 强调情绪，关键信息 |
| 大特写 | 眼睛/手部等极致细节 | 情绪爆发，重要线索 |
| 低角仰拍 | 从低处向上 | 强化人物力量感、权威感 |
| 俯拍 | 从高处向下 | 渺小感、压迫感、宏观视角 |

## 台词处理规则（神圣原则）

**台词是神圣的。不能省略，不能改写，不能合并不同人物的台词。**

### 对白标注格式

| 标注 | 含义 | 示例 |
|------|------|------|
| `角色名（os）` | 画外音/内心独白（人在画面中但不出声） | 林冲（os）：这世道... |
| `角色名（vo）` | 旁白（人不在画面中） | 陆谦（vo）：这把火下去... |
| `角色名（情绪）` | 带情绪的对白 | 林冲（怒吼）：奸贼！纳命来！ |
| `角色名（惊/怒/喜）` | 情绪标注变体 | 林冲（惊）：这…… |
| `角色名` | 普通对白 | 林冲：且去山神庙暂避一夜。 |
| `【字幕：xxx】` | 屏幕文字/字幕 | 【字幕：沧州草料场 看守 林冲】 |

### 长台词处理

超过50字（约5秒）的台词，拆成多个分镜：
- 分镜1：说前半段，画面对应说话的人
- 分镜2：说后半段，画面可切到听者反应
- 每个分镜的台词栏只写该分镜对应的那段，后面加"（续）"

### 无台词分镜

```
台词：无
```

## 合并与拆分规则

**可以合并进同一个分镜：**
1. 同一空间内的连续小动作
   - 例：刘倩走进来 → 站在病床边 → 冷笑 → 合并为一个分镜
2. 表情/情绪的层层变化
3. 短句台词 + 即时反应（合计不超过5秒）
4. 时长较短的内心独白（OS）

**不能合并（必须单独成镜）：**
- 场景切换（室内→室外，现代→古代）
- 时间跳切（有字幕"八年之后"等）
- 情绪/节奏的强对比（紧张→温柔）
- 重要道具特写（合约、武器、关键物品）

| 元素 | 格式 | 示例 |

### 场景切换分镜（3秒过渡）
每次出现新场景，单独开一个过渡分镜：
```
△ 【场景切换】画面从[A场景]切换到[B场景]，[简单的转场描述]。
时长：3秒
```

## 动作序列描述

**使用 → 连接连续动作，而不是写成多个分镜：**

```
❌ 错误：
△ 林冲刺向差拨。
△ 差拨倒下。
△ 林冲转向富安。

✅ 正确：
△ 林冲如天神下凡般冲出，花枪一抖，枪尖带着寒芒。
林冲（怒吼）：奸贼！纳命来！
△ 陆谦惊恐后退，林冲一枪刺穿差拨胸膛，鲜血喷溅在洁白的雪地上 → 富安想逃，被林冲回身一枪斩断双腿，倒地哀嚎 → 陆谦跪地求饶，面容扭曲。
```

## 感官细节（必须在每个镜头中体现）

优秀的分镜需要调动多种感官：

| 感官 | 描述词汇示例 |
|------|------------|
| **视觉** | 颜色（灰白、暗红、鲜红）、光影（侧光、剪影、火光映照、逆光轮廓）、构图（对角线、对称、景深） |
| **听觉** | 呼啸声、咯吱声（雪地脚步）、噼啪声（火焰）、沉重、急促、凄厉如鬼哭狼嚎 |
| **触觉/温度** | 寒风刺骨、冰冷的雪、灼热的愤怒、指节因用力而泛白 |
| **情绪** | 孤寂、惊疑、压抑、决绝、爆发、冰冷 |

**❌ 不好（只有视觉）：**
```
△ 林冲站在雪地里。
```

**✅ 好（多感官）：**
```
△ 林冲头戴毡笠，身披破旧蓑衣，独自倚在草料堆旁。他抬起头，眼神中透着深深的疲惫与无奈，呼出的白气瞬间消散在凛冽的寒风中。
```

## 分镜编号规范

- 集-场景-镜号三级编号：`1-1-001`、`1-1-002`...
- 场景切换后，镜号继续往下计，不重置
- 单场景可直接从001开始

## 快速质量自检

完成一集后逐条检查：
- [ ] 每个镜头以 `△ ` 开头
- [ ] 运镜使用了具体术语（推/拉/摇/移/跟/环绕/升降）
- [ ] 对白格式正确（os/vo/情绪）
- [ ] 包含感官细节（至少视觉+听觉）
- [ ] 无任何台词被省略或改写
- [ ] 有情绪弧线（建立→上升→高潮→释放）
- [ ] 动作序列用 → 连接
- [ ] 每个镜头有叙事目的（可回答"这个镜头为什么存在"）
