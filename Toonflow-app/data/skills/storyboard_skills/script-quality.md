# 好剧本标准

## 核心梗类型速查

在开始写剧本前，先用2-4字锁定核心梗。核心梗决定整部剧的情绪基调和用户预期。

| 核心梗 | 示例作品 | 情绪爆点 |
|--------|---------|---------|
| 绝境反杀 | 林冲风雪山神庙 | 压抑→爆发，隐忍值清零 |
| 复仇爽剧 | 基督山伯爵 | 遭背叛→蛰伏→绝地反击 |
| 治愈温馨 | 多拉A梦 | 日常温暖，情感共鸣 |
| 悬疑惊悚 | 命运石之门 | 充满反转，信息不对称 |
| 成长励志 | 灌篮高手 | 主角通过努力突破自我 |
| 爱情故事 | 泰坦尼克号 | 感情线为主轴 |
| 史诗战争 | 崖山海战 | 宏大叙事，家国情怀 |
| 经典武侠 | 聂风/武松 | 热血江湖，痛快淋漓 |

---

## 一句话卖点公式

**公式：** [情绪号召] + [核心冲突] + [视觉高潮画面]

**好的示例：**
- 忍无可忍，无须再忍！风雪夜，豹子头林冲长枪出鞘，血溅山神庙！
- 临危不乱，机智救人！孩童司马光砸缸救人，展现超乎常人的冷静！
- 一人一枪一碗酒，鲁智深五台山大闹酒禁，这身佛门袈裟遮不住的满腔烈火！

**❌ 不好的示例（太抽象）：**
- 这是一个关于勇气和正义的故事
- 主角最终战胜了敌人

## 人物小传标准格式

**每个主要角色必须包含以下五项，缺一不可：**

```
角色名
视觉形象：[年龄] + [外貌特征（具体细节）] + [服装] + [标志性道具]
身份背景：[社会身份] + [与主角关系] + [核心过往]
核心标签：[标签1] + [标签2] + [标签3]（2-4个，用于提示词）
性格特点：[正常状态] → [压力下] → [爆发/转折时]（写出弧线）
金句：[最能代表角色的台词，用双引号]
```

**Character Bible（AI生成用）：**
```
英文固定词组：[English fixed description words for AI prompts]
Want：[外部目标]
Need：[内在需要]
Arc：[弧光转变路径]
```

**❌ 简单版（不可用）：**
```
林冲：30多岁，禁军教头，性格隐忍
```

**✅ 完整版（标准格式）：**
```
林冲
视觉形象：三十多岁，面容刚毅沧桑，身穿破旧棉袄，头戴毡笠，手持花枪，腰悬酒葫芦。
身份背景：前八十万禁军教头，现沧州囚犯，遭高太尉陷害发配。
核心标签：隐忍不发、悲情英雄、杀神降临。
性格特点：原本委曲求全，只想安分守己；接连受辱后内心岌岌可危；被逼入绝境后爆发出极强的决绝与杀伐之气。
金句："这世道，逼好人做鬼！"

Character Bible：
英文固定词组：Chinese man in his late 30s, tall and lean, black hair in traditional bun, refined scholarly appearance, wearing a weathered dark cotton soldier's jacket, bamboo hat, carrying a long spear
Want：安分守己，保护家人，继续当教头的好日子
Need：认清这个世道不会因为他的隐忍而放过他
Arc：委曲求全 → 一再受辱 → 草料场被火 → 绝望爆发 → 清醒复仇
```

## 剧本大纲结构

### 三幕结构（5集以内）
```
前期（起）：建立场景 + 主角现状 + 触发事件（打破平衡）
中期（承/转）：冲突发展 + 1-2次挫折 + 关键转折点
后期（高潮）：最终对决 + 情感/动作爆发
尾声（收尾）：结局状态 + 主题升华（可选余韵）
```

### 四幕结构（10-20集）
```
起（1/4时长）：世界建立，主角登场，初始冲突
承（1/4时长）：冲突加剧，多重障碍，主角受挫
转（1/4时长）：关键转折，真相揭示，主角觉醒/爆发
合（1/4时长）：决战，高潮，结局，余韵
```

## 色彩情绪规划

好剧本会提前规划每个阶段的色调，让视觉情绪与叙事情绪同步。

| 叙事阶段 | 推荐色调 | 情感目的 |
|---------|---------|---------|
| 开场（压抑/建立） | 灰白、墨黑、冷蓝 | 孤寂、压抑、危机暗藏 |
| 发展（危机加深） | 暗黄、灰绿 | 警惕、不安 |
| 转折（真相揭露） | 深红、橙红 | 愤怒、震惊 |
| 高潮（爆发） | 鲜红对比纯白、金色 | 热血、决绝 |
| 尾声（余韵） | 苍茫白、淡墨 | 孤独、升华 |

**视觉母题（贯穿全剧的意象）：**
选择1-3个反复出现的视觉元素，赋予象征意义。

示例（林冲）：
- 风雪：贯穿全剧，象征命运无情
- 长枪：E1看守武器 → E5复仇利器，角色转变的载体
- 酒葫芦：E1逃避现实 → E3最后一口 → E5彻底放下

## 质量自检

写完剧本后确认：
- [ ] 核心梗2-4字能说清楚
- [ ] 一句话卖点有情绪号召 + 具体画面
- [ ] 每个主要角色有完整五项小传
- [ ] Character Bible 英文固定词组已建立
- [ ] Want/Need/Arc 三元结构已填写
- [ ] 人物性格写出了弧线（状态变化），不是静态描述
- [ ] 金句是角色说的，不是旁白评论
- [ ] 剧本大纲有明确的转折点（让剧情不可预测）
- [ ] 色彩情绪有规划
- [ ] 视觉母题1-3个已定义
