# 复古像素艺术风格说明

本风格专为"复古像素艺术风格"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **像素设计风格**：以像素设计（Pixel Art）为核心，涵盖UI设计、信息图表、插画等，体现现代简约美学。
- **有限色色块质感**：所有角色、场景、道具均以2D像素风格为标准，强调有限色填充、阶梯明暗与可控抖色、像素轮廓。
- **简约现代美学**：在像素风格基础上追求清晰表达，画面色调明快简洁，细节简化，整体氛围简约现代、舒适宜人。
- **情感表达**：适合展现温柔、治愈、浪漫的像素风格内容，强调现代简约美学下的情感表达。

## 适用范围

- 2D像素风题材的AI美术生成（角色、场景、道具、分镜等）
- 需要极致像素质感、像素轮廓、现代简约氛围的视觉创作

## 严禁内容

- 写实渲染、3D渲染、照片级真实感
- 阴影、渐变、纹理、光影
- 复杂细节、精细纹理、写实背景
- 黑暗暴力、成人向内容

## 风格体验

在本风格下，您将体验到：

- 角色面容简约、气质清新，造型、服饰均为2D像素设计风格
- 场景空间层次简洁，线条清晰流畅，氛围真实且富有现代感
- 道具、日常物品、环境细节均为像素化造型，工艺简洁，质感清爽
- 分镜与画面均以2D像素为基础，强调叙事与情感表达

---

本风格仅适用于"复古像素艺术风格"相关项目。如需其他风格（如写实3D、插画、现代3D等），请勿使用本套提示词。
