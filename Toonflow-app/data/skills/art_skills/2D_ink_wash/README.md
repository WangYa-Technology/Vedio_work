# 东方水墨画风格说明

本风格专为"水墨水墨插画留白意境"题材打造，所有美术提示词、规范和生成内容均严格限定于：

- **水墨水墨插画动画**：以中国古风文化为背景的水墨插画动画风格，涵盖仙侠、武侠、宫廷等题材
- **留白意境美学**：传统东方元素与现代审美结合，古典韵味与时尚感并存
- **日式动画渲染技法**：现代日式动画的上色与光影技术，赛璐璐平涂结合数字渲染
- **东方古韵**：诗意氛围、留白构图、意境深远的东方美学表达
- **细腻笔触**：清晰的线条、精细的细节、精致的角色与场景设计
- **水墨水墨插画电影质感**：电影级构图、光影层次、动态张力、情绪氛围

## 适用范围

- 水墨水墨插画题材的AI美术生成（角色、场景、道具、分镜等）
- 需要留白意境美学、日式动画渲染、水墨意境的视觉创作
- 水墨动画、游戏美术、概念设计、插画创作

## 严禁内容

- 完全写实摄影/3D写实渲染
- 西方奇幻/哥特/维多利亚风格
- 赛博朋克/科幻/过度现代元素
- 粗劣线条/模糊画质/低精度建模
- 色彩混乱/风格不统一/审美崩坏
