# 半写实 3D 漫提示词推理模板

1. 先确定写实与动画化的边界：可信人体结构和材质基础，加适度理想化脸型、眼睛与轮廓比例。
2. 皮肤、头发、织物保留细腻材质，但降低毛孔和高频噪声；光影柔和电影化，不转成照片真人。
3. 表情使用细微肌肉变化与动画可读性结合，动作遵循重心和关节，同时保留优雅姿态线。
4. 镜头采用克制景深、缓推、跟拍或环绕，固定角色模型、五官比例、妆发、服装和材质响应。
5. 角色生图遇到「高精度3D半写实国漫、BJD人偶、成年少女、甜美纯欲、梦幻偶像、轻哥特、Y2K、洛丽塔、甜酷Coquette、精灵、御姐、女团、明星偶像、轻奢穿搭、高级黑、冷感美少年、痞帅校园、暗黑街头、精英西装、ai男主、建模脸cos、少年偶像、韩系高街、静奢、轻Y2K、学院休闲、潮流针织、牛仔、机能、轻朋克、国漫古风美男、华服、角色四视图」等线索时，必须按「年龄安全 -> 脸型/骨相 -> 眉眼 -> 鼻唇 -> 肤感 -> 发丝 -> 身高头身比 -> 服装材质 -> 配饰 -> 横向四视图版式 -> 影棚光」顺序提炼，保留用户给出的具体锚点。
6. 四视图角色设定板默认使用浅灰无缝影棚背景、左侧大幅正脸特写、右侧正面/侧面/背面全身，要求同一人物面容、发型、服装、比例一致，避免裁切头脚。
7. 成年少女幻想风必须区分于幼态风：保留甜美感与梦幻感，但年龄判断必须落在成年年轻女性，不得使用幼童、大头娃娃、廉价Cos或单一配色的简化表达；甜酷Coquette 要同时保留甜美、复古、精致装饰和轻微俏皮感。现代高级黑男性风必须明确年轻成年男性，保留冷冽攻击感、220cm/九头身或用户指定比例、都市轻奢高定质感，不得误转成女性化、幼态化或真人写真。少年偶像/韩系高街风必须锁定年轻成年男性、清冷高级偶像气质、220cm九头身、宽松但有结构的高街服装、静奢/轻Y2K/轻机能/轻朋克的克制融合，不得变成普通运动服、紧身服、老气商务装或廉价塑料质感。
8. 禁止一镜内真人与卡通来回跳变、过大眼睛、蜡质皮肤、关节穿插、光影漂移、随机文字、水印、尺标和标签。
