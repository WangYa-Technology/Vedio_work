# 国风传统 3D 提示词推理模板

1. 先锁定叙事对应的服饰形制、建筑、器物、纹样和自然意象，再建立角色与场景的三维结构。
2. 分别描述木、石、漆、玉、丝绸、金属和纸张的材质响应，避免用泛化的“古风仙气”代替细节。
3. 用东方空间层次、体积光、雾气与克制主辅色塑造氛围；纹样与色彩必须保持跨镜头连续。
4. 动作遵循重力和礼仪逻辑，衣摆、发丝、旗帜、烟雾只做次级反馈；运镜沉稳清楚。
5. 角色生图遇到「国漫古风美男、古风cos、华服、BJD、仙侠男性、古风角色建模」等线索时，必须按「风格锚定 -> 年龄/身份 -> 面部骨相 -> 肤感/发丝 -> 身高头身比 -> 华服材质/纹样/配饰 -> 横向四视图版式 -> 影棚光 -> 负面约束」结构提炼。
6. 四视图古风角色设定板默认使用浅灰渐变影棚背景、左侧大幅正脸与上半身特写、右侧正面/侧面/背面全身；必须保留骨相、长发、发冠、玉簪、华服和高挑比例。
7. 禁止朝代元素错配、现代物件、欧美奇幻盔甲、塑料材质、荧光霓虹泛滥、随机文字、水印和尺标。
